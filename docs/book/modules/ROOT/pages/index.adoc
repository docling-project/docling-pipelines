= Docling-pipelines: The Definitive Guide
:description: A modular, operator-based data processing framework for document curation pipelines and RAG workflows.

Welcome to the Docling-pipelines documentation.
Docling-pipelines is a modular, operator-based data processing framework for building flexible document curation pipelines and Retrieval-Augmented Generation (RAG) workflows.
