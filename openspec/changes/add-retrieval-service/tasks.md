## Group 3: Adapters (Catalog, DuckDB SQL, Vector Backends, LLM, Cache, ACL)

- [ ] 3.1 `[backend]` Implement `LocalRetrievalCatalogAdapter` (`adapters/catalog/local_catalog_adapter.py`) as a thin wrapper over `DerivativeResolverPort` (blocked on #639 and `add-document-library-derivatives`; develop against a fake resolver). It adds only: `retrieval.vector_stores` connection merge with `$VAR`/`${VAR}` secret resolution (one cluster per provider), the `SqlTableTarget(kind="document_set_table")` from the storage attachment, `document_classes/*.json` enrichment, optional `DocumentSet.metadata["retrieval_derivatives"]` overrides (including `acl_protected`, `column_mapping`), resolver-null fallbacks (embedding provider, sparse flag, operator-default column names; none for `allowed_users`), and surfacing resolver `conflicts` as a generic note. It MUST NOT read the card's embedding `feature` as an index field.
- [ ] 3.2 `[backend]` Implement `SqlValidator` (`application/sql_validator.py`) using `sqlglot` (`duckdb` dialect) as an allowlist: single `SELECT` only, plain unqualified allowlisted tables or in-statement CTEs only, rejection of every table-valued function and of catalog/schema-qualified names, a fixed in-code scalar/aggregate function allowlist, fail-closed on unknown AST nodes, CTE-shadowing rejection, and output of the re-serialized AST SQL for execution.
- [ ] 3.3 `[backend]` Implement `DuckDBSqlEngine` (`adapters/sql/duckdb_sql_engine.py`) that obtains connections only via `DuckDBConnectionManager` (`locked` mode with `lock_timeout_seconds`, and opt-in `snapshot` mode that, under the source lock, single-flight copies ONLY the allowlisted tables of the queried sets into a new file under a `0700` `snapshot_dir` with `0600` files, written under a temporary name and atomically renamed), applies `SET enable_external_access = false`, `SET lock_configuration = true`, `max_memory`, `threads` after trusted `DESCRIBE` introspection, enforces `max_rows`, `asyncio.to_thread` offloading, timeout enforcement, and `conn.interrupt()` cancellation via `CancelHandle`. Reject `SqlTableTarget(kind="entity_table")` as unsupported.
- [ ] 3.4 `[backend]` Implement `MilvusVectorQueryAdapter` (`adapters/vector/milvus_query_adapter.py`) supporting hybrid dense + BM25 RRF search with dense-only fallback via `pymilvus` in `asyncio.to_thread`.
- [ ] 3.5 `[backend]` Implement `OpenSearchVectorQueryAdapter` (`adapters/vector/opensearch_query_adapter.py`) supporting k-NN / hybrid search and `allowed_users` ACL filtering via `opensearch-py`.
- [ ] 3.6 `[backend]` Implement `WeaviateVectorQueryAdapter` (`adapters/vector/weaviate_query_adapter.py`) using `weaviate-client` v4 (`near_vector` on the mapped `vector_field`, `hybrid` for BM25 mode, deterministic client cleanup).
- [ ] 3.7 `[backend]` Implement `InferenceBridge`, `EmbeddingBridge`, and optional `RerankerPort` adapters (`ollama`, `watsonx`, `cross_encoder`) under `adapters/llm/`, wrapping `docpipe`'s `LLMInferencePort` and `LLMEmbeddingPort` with `asyncio.to_thread`.
- [ ] 3.8 `[backend]` Implement `MemoryRetrievalCache` (`cachetools.TTLCache`), optional `RedisRetrievalCache`, and `DocpipeACLAdapter` under `adapters/cache/` and `adapters/acl/`.

## Group 4: Application Layer & Factory Wiring

- [ ] 4.1 `[backend]` Implement `SqlRetriever` (`application/sql_retriever.py`) with `retrieval.sql.enabled` gating, automatic skip for ACL-protected document sets, schema + document-class prompt synthesis, correlation-key instruction, `SqlValidator` gate, and bounded `max_retries` self-correction loop that fails fast on non-repairable errors (authorization, timeout, cancellation, lock-acquire timeout, connection).
- [ ] 4.2 `[backend]` Implement `VectorRetriever` (`application/vector_retriever.py`) with concurrent per-target dispatch, expanded `max(limit, rerank_candidates)` pool when reranker is configured, graceful reranker fallback, and fail-closed handling of ACL-protected sets (mandatory `allowed_users` on OpenSearch only when its `allowed_users` mapping is known, skip OpenSearch otherwise, skip Milvus/Weaviate with a generic `acl_protected_store_skipped` note).
- [ ] 4.3 `[backend]` Implement `Synthesizer` (`application/synthesizer.py`) for unified SQL Markdown + deduplicated vector-chunk context formatting and grounded LLM answer generation.
- [ ] 4.4 `[backend]` Implement `SearchOrchestrator` (`application/search_orchestrator.py`) and `SearchJobQueue` (`application/job_queue.py`) with cache lookup/write, concurrent SQL + vector execution, partial-status degradation, per-user job ownership (`404` on cross-user poll), queue depth limit (100 → `503`), and result TTL (900s / max 2,048).
- [ ] 4.5 `[backend]` Implement `OuterQueryPlanner`, `DAGExecutor`, and `MultiDocSetOrchestrator` (`application/outer_planner.py`, `dag_executor.py`, `multi_docset_orchestrator.py`) with single-set fast-path and wave-parallel multi-set execution.
